L'objectif de ce projet est de concevoir un site web adapté aux besoins et attentes d'une personne spécifique.

Conception et développement d'un site web sur mesure avec EJS et base de données SQL.
Technologies : EJS, SQL

Missions

Dans le cadre de ce projet, nous avons suivi une méthodologie complète de développement web :

Étapes clés

  • Analyse approfondie des besoins du client pour bien comprendre ses attentes
  • Conception des wireframes pour structurer les différentes pages du site
  • Création des maquettes pour visualiser le rendu final
  • Développement du site web en utilisant le moteur de templates EJS
  • Création et gestion d'une base de données SQL sur mesure
  • Présentation orale finale pour démontrer la qualité du travail réalisé
